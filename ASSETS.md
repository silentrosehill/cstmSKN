# Interface assets and data

- Navigation and control symbols in `src/assets/symbols/` are rasterized SF Symbols supplied by macOS AppKit. `src-tauri/scripts/export-symbols.swift` reproduces them on macOS. They appear in Apple-platform interfaces; other platforms use Lucide. SF Symbols remain subject to Apple's terms: https://developer.apple.com/sf-symbols/ and https://developer.apple.com/design/human-interface-guidelines/sf-symbols/. The application icon is a separate custom design.
- Typography uses the macOS system font through `-apple-system`; no Apple font files are bundled.
- Champion portraits, splash artwork, the current version list, and patch skin metadata come from Riot Data Dragon: https://developer.riotgames.com/docs/lol#data-dragon. New Releases compares the latest build with the latest build of the previous patch and excludes default skins, chromas, and alternate Classic champions. Riot's publication schedule determines when new patch data becomes available.
- The champion release-date snapshot combines https://github.com/meraki-analytics/lolstaticdata with Riot's Universe champion index at https://universe-meeps.leagueoflegends.com/v1/en_us/champion-browse/index.json. Locke's launch date follows Riot's official 26.13 patch notes: https://www.leagueoflegends.com/en-sg/news/game-updates/league-of-legends-patch-26-13-notes/.
- Artwork-based interface colors are calculated locally from the selected splash. Dark/light appearance and readable text contrast are preserved. The user's manual accent returns when leaving the artwork gallery.

- Skin rarity tags use the client `rarity` field from CommunityDragon’s exported Riot skin metadata, not a price-based estimate: https://raw.communitydragon.org/latest/plugins/rcp-be-lol-game-data/global/default/v1/skins.json. The bundled skin/chroma tier snapshot supports immediate and offline display; live metadata refreshes through the existing 24-hour data cache. To refresh the build-time snapshot, run `node --experimental-strip-types scripts/update-skin-rarities.mjs`.

- Installed-skin portraits use Riot’s loading-screen assets at `https://ddragon.leagueoflegends.com/cdn/img/champion/loading/{Champion}_{skinNum}.jpg`, documented under Champion Loading Screen Assets: https://developer.riotgames.com/docs/lol#data-dragon. Skin numbers resolve through the existing chroma-to-parent lookup.

- Native sidebar glass is Apple AppKit’s untinted `NSGlassEffectView`, looked up at runtime for macOS 26+. The Objective-C bridge is compiled with the existing macOS developer tools and falls back to the configured sidebar material on older systems. Documentation: https://developer.apple.com/documentation/appkit/nsglasseffectview and https://developer.apple.com/design/human-interface-guidelines/materials.
